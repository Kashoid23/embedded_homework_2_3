## Як це працює

Кожен світлодіод зберігає свій півперіод і час останнього перемикання. Цикл не чекає, а лише перевіряє, чи настав час перемкнути світлодіод:

```c
if ((uint32_t)(now - led->last_change_timestamp) >= led->half_period)
{
    HAL_GPIO_TogglePin(led->port, led->pin);
    led->last_change_timestamp = now;
}
```

### Мінімальний час циклу

`HAL_GetTick()` змінюється раз на 1 мс. Якщо мілісекунда ще не минула, нічого змінитися не могло, тому цикл виконує лише одне порівняння і переходить до наступного проходу:

```c
if (now == last_tick)
{
    continue;
}
```

Кнопки і світлодіоди обробляються лише раз на мілісекунду.

### Кнопки

- Натискання зараховується, коли кнопка 20 мс (`DEBOUNCE_MS`) стабільно натиснута. Так відкидається брязкіт контактів.
- Одне натискання спрацьовує один раз, навіть якщо кнопку тримати.
- **Button 1** вмикає паузу: усі світлодіоди гаснуть. Друге натискання відновлює блимання з початку періоду.
- **Button 2** перемикає період LED3 по колу: 1000 → 500 → 200 мс.

## Запуск

1. Відкрити проєкт у STM32CubeIDE.
2. **Project → Build Project**.
3. **Run** через ST-Link.
